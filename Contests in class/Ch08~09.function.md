# Number Operations via Functions

**Time limit:** 1 s &nbsp;|&nbsp; **Memory limit:** 64 MB &nbsp;|&nbsp; **Points:** 100 (Case 1: 50 pts, Cases 2–6: 10 pts each)

---

Practice writing functions with parameters and return values in C.

Your program MUST implement and call at least three functions:

- `get_double(int n)` – returns twice the number.
- `get_square(int n)` – returns the square of the number.
- `get_sum(int a, int b)` – returns the sum of two numbers.

Each function must return a value using the `return` statement.

## Input

Line 1: Two integers `a` and `b`, separated by a space.

Constraints:
- `1 <= a, b <= 100`

## Output

Print three lines:

```text
Double: <double of a>
Square: <square of b>
Sum: <sum of a and b>
```

## Sample Input

```text
3 5
```

## Sample Output

```text
Double: 6
Square: 25
Sum: 8
```
