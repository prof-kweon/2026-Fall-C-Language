# Basic Arithmetic

**Time limit:** 1 s &nbsp;|&nbsp; **Memory limit:** 64 MB &nbsp;|&nbsp; **Points:** 50 (Case 1: 50 pts)

---

Write a C program that uses two integer variables.

## Setup

Set the values as follows:
```c
int x = 20;
int y = 10;
```

## Task

Calculate and print:
1. The sum of the two numbers.
2. The difference between the two numbers.
3. The product of the two numbers.
4. The quotient of the two numbers.

## Output

Print exactly four lines, in this order:
```
Sum: <x+y>
Difference: <x-y>
Product: <x*y>
Quotient: <x/y>
```

## Sample Output
```
Sum: 30
Difference: 10
Product: 200
Quotient: 2
```

**Hint:** Use the operators `+`, `-`, `*`, and `/`, and use `printf()` to display the results.
