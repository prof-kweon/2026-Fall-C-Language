# Fix the Bugs

**Time limit:** 1 s &nbsp;|&nbsp; **Memory limit:** 64 MB &nbsp;|&nbsp; **Points:** 100 (Case 1: 50 pts, Cases 2-6: 10 pts each)

Below is a C program that is supposed to do the following:

1. Read an integer `x` and a name.
2. Print `Hello, <name>`.
3. If `x` equals `5`, print `x is 5`.
4. Print `This line has no newline`.

However, the program below has **several bugs** — some prevent it from compiling, others are silent logic errors. Fix all of them so the program behaves as described above.

```c
#include <stdio.h>

int Main(void)
{
    int x;
    printf("Hello, %s", name);
    if (x = 5) {
        printf("x is 5\n");
    }
    printf("This line has no newline");
    return 0
}
```

## Hints

- Is the function name spelled correctly?
- Where do `x` and `name` get their values from? (Hint: you need to read them from input.)
- `=` and `==` do very different things.
- Does every line end the way it should — both in terms of punctuation and output formatting?

## Input

- Line 1: an integer `x`.
- Line 2: a name (one word, no spaces, 1-20 letters).

## Output

- `Hello, <name>`
- `x is 5` (only printed if `x` is exactly `5`)
- `This line has no newline`

## Sample Input
```
5
Tommy
```

## Sample Output
```
Hello, Tommy
x is 5
This line has no newline
```
