# Random Array Statistics

## Problem Description

Write a C program that generates **100 random integers between 1 and 100 (inclusive)** using `rand()`.

Store the generated numbers in an integer array and calculate the following statistics:

1. **Minimum:** The smallest number in the array.
2. **Maximum:** The largest number in the array.
3. **Average:** The arithmetic mean of all 100 numbers.

Use `srand()` with `time(NULL)` to initialize the random number generator.

## Requirements

Your program must:

- Define an integer array of size **100**.
- Initialize the random number generator using `srand((unsigned int)time(NULL))`.
- Generate 100 random integers using `rand() % 100 + 1`.
- Store all generated numbers in the array.
- Use loops to find the minimum and maximum values.
- Calculate the average using floating-point division.
- Print the average with exactly **two decimal places**.

## Input Specification

There is **no input**.

Your program must generate the 100 random integers.

## Output Specification

Print the following information in the specified order:

1. All 100 generated integers on a single line, separated by spaces.
2. The minimum value.
3. The maximum value.
4. The average value, rounded to two decimal places.

Use the following output format:

```text
<number1> <number2> ... <number100>
Min: <minimum>
Max: <maximum>
Average: <average>
```

## Sample Input (No input)

## Sample Output

The following is an illustrative example. The actual numbers will vary each time the program runs.

```text
50 50 50 50 50 ... 50
Min: 50
Max: 50
Average: 50.00
```

## Notes

- Each generated integer must be between **1 and 100**, inclusive.
- The minimum and maximum must be calculated from the generated array.
- The average must use `%.2f` to print the average with two decimal places.
- Different executions may produce different random numbers.
