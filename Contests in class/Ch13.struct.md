# The Class Line

**Time limit:** 1 s &nbsp;|&nbsp; **Memory limit:** 64 MB &nbsp;|&nbsp; **Points:** 100 (Case 1: 50 pts, Cases 2-6: 10 pts each)

---

Before a class photo, the teacher makes a list of students.
Each student card has a number, a name, a grade, and a **pointer to the birthday** of the student.
The birthday is a small card of its own: a year, a month and a day.
Three students are already in the list, with their birthdays. **You are the 4th student.**
Read your own data. Then the teacher goes through the list and reports.

![The class list: four student cards, each with a birthday pointer to a date card](/media/struct2_diagram.png?v=1)

The picture shows the data after your input is read. The 4th card (yellow) has your own data.

A starter program is already in your code editor. Write your code under the comments.

## What to do
1. The starter has two structures:
```c
struct date {
    int year;
    int month;
    int day;
};
struct student {
    int number;
    char name[10];
    double grade;
    struct date *birthday;
};
```
2. The starter has `struct date dates[4]` and `struct student list[4]`. The first 3 students and their birthdays are already set. Each `birthday` points to a `dates[...]` element.
3. Read the 4th student with **two** `scanf` calls:
   - First `scanf`: your ID, your first name and your grade into `list[3]`. Read the name with `%9s`.
   - Then make `list[3].birthday` point to `dates[3]`.
   - Second `scanf`: your birth year, month and day. Read them through the pointer `list[3].birthday`.
4. Use **one `for` loop** over the array `list`. For each student print one line, add the grade to the total, and remember the student with the highest grade.
5. After the loop print the total, the average and the best student.

## Input
Two lines.
- Line 1: `number name grade` of the 4th student.
  - `number` is a 9-digit student ID.
  - `name` is a first name with at most 9 letters and no spaces. `char name[10]` holds 9 letters and the end mark `'\0'`, so `%9s` cannot overflow it.
  - `grade` is from 0 to 4.5 with at most 2 decimals.
- Line 2: `year month day`, the birthday of the 4th student (three integers).

## Output
```
Student 1: <number> <name> <grade> <birthday>
Student 2: <number> <name> <grade> <birthday>
Student 3: <number> <name> <grade> <birthday>
Student 4: <number> <name> <grade> <birthday>
Total: <the sum of the 4 grades>
Average: <total divided by 4>
Best: <the name of the student with the highest grade>
```
- Print a grade, the total and the average with 2 decimals (`%.2f`).
- Print a birthday as `yyyy-mm-dd`, for example `2006-05-09` (`%04d-%02d-%02d`).
- If two students have the same highest grade, print the first one in the list.
- Print nothing else.

## Hints
- `scanf` reads an `int` with `%d`, a `double` with `%lf` and a string with `%9s` (no `&` for a string).
- `list[3].birthday = &dates[3];` makes the birthday pointer of student 3 point to `dates[3]`. Do this **before** the second `scanf`.
- Through a pointer, use `->`: `list[3].birthday->year` is the year that the pointer points to. Its address is `&list[3].birthday->year`.
- For the best student, keep the index `best` of the best student so far. Change it with `best = i;`.

## Sample Input
```
202644444 Choi 3.85
2006 5 9
```

## Sample Output
```
Student 1: 202611111 Park 3.42 2005-03-15
Student 2: 202622222 Kim 4.31 2004-11-02
Student 3: 202633333 Lee 2.98 2006-07-21
Student 4: 202644444 Choi 3.85 2006-05-09
Total: 14.56
Average: 3.64
Best: Kim
```

## Scoring
There are 6 test cases. Case 1 is the sample (50 points). Cases 2-6 are worth 10 points each.
In every test case you can get:

- **50%** - Your program compiles and runs, and prints the result lines. (You get nothing if you did nothing yet.)
- **20%** - The four `Student` lines are correct. This means your own ID, name, grade and birthday were read correctly.
- **10%** - The `Total` line is correct.
- **10%** - The `Average` line is correct.
- **10%** - The `Best` line is correct.

If you do not get 100, the judge shows your output and a short message.
`Out:Total` means the `Total` line is wrong. `Out:Students` means a `Student` line is wrong.
