# Operator Playground

**Time limit:** 1 s &nbsp;|&nbsp; **Memory limit:** 64 MB &nbsp;|&nbsp; **Points:** 100 (Case 1: 50 pts, Cases 2-6: 10 pts each)

---

Practice increment/decrement and the ternary operator.

## Input
One line with a single integer `x` (-1000 <= x <= 1000).

## Output
Three lines:
```
Parity: EVEN or ODD
Pre-increment: <++x>
Doubled original: <2 * original x>
```
(Note: "Doubled original" uses the ORIGINAL value of x, before the increment.)

## Sample Input
```
4
```

## Sample Output
```
Parity: EVEN
Pre-increment: 5
Doubled original: 8
```
