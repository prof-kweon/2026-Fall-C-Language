# Array Max via Pointer Traversal (ID Seed)

---

Your program MUST traverse the array using pointer arithmetic (e.g. `*(p+i)` or `p++`), and find the maximum via a function that returns a POINTER to the max element.

## Task

1. Use **your own student ID** (9 digits) as the seed. Write it in your code, for example `#define STUDENT_ID 202612345`, and call `srand(STUDENT_ID);`
2. Print the seed on the first line: `Seed: <your student ID>`
3. Generate **10** random integers, each as `rand() % 100 + 1` (so every value is between 1 and 100), and store them in an array.
4. Print the 10 numbers on one line, separated by single spaces.
5. Find the maximum with a function that returns a pointer to the maximum element, then print the maximum value and the 0-based index of its **first** occurrence (hint: the index is the pointer difference `p - arr`).

Because every student has a different ID, every student gets different numbers.
Don't forget `#include <stdlib.h>` for `srand()` and `rand()`. Do not print anything else.

## Input
There is no input.

## Output
Four lines:
```
Seed: <your student ID>
<the 10 numbers, separated by single spaces>
Max: <max value>
Index: <0-based index of the FIRST occurrence of the max>
```

## Sample Output (for the student ID 202612048)
```
Seed: 202612048
66 60 4 48 68 78 29 33 29 78
Max: 78
Index: 5
```
The maximum 78 appears twice (index 5 and index 8), so `Index` is the first one: 5.
Your own numbers will be different, because your ID is different.
