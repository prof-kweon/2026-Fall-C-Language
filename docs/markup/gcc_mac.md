# How to Install GCC on macOS

## 1. Open Terminal
  Open **Terminal** on your Mac.
  You can find it here: **Applications → Utilities → Terminal**

## 2. Install Command Line Tools
  In Terminal, type: `xcode-select --install`
  Press **Enter**.

## 3. Start the Installation
A pop-up window will appear.
Click **Install** and follow the instructions.
Wait until the installation is complete.

## 4. Check GCC
Open Terminal and type: `gcc --version`
Then press **Enter**.

## 5. Done!
  If you see version information, the compiler is installed correctly.

### Note
  On macOS, the `gcc` command usually uses the **Apple Clang compiler**. This is fine for most C and C++ programming exercises.
